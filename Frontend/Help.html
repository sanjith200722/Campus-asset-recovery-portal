HOW TO USE WEBSITE

1. Welcome / Start Page:

This is the welcome page of the Campus Asset Recovery Portal. It introduces the system to the user.
The blue text “click here” is a link. Click this link to continue to the main portal.

2.View Items / Posts Page

This page shows all posted lost and found items.
Users can see:

  • Item image
  • Type (Lost / Found)
  • Location
  • Date
  • Description
  • Contact number
The blue text “click here” is a link to go to login/register page.

3.Filter Option

This feature helps users search items easily.
Users can filter by:

  • Category
  • Type (Lost / Found)
Click Filter button to apply filter.
Click Clear Filter to reset results.

4.Login Page

This page is used by registered users to log in.Users must enter username and password.
The blue text “Click here” is a link to go to the register page if the user is new.

5.Register Page

This page allows new users to create an account.
Users must fill:

  • Name
  • Username
  • Contact Number
  • Profile Picture
  • Password
The blue text “Click here” is a link for users who already have an account to go to login page.

6.Main Home Page

This is the main home page of the system.
Users can navigate using buttons:

  • Report/Found Lost Items → Go to post item page
  • Profile → View user details
  • View Posted Items → See all items
Navigation bar buttons (Home, Profile, Post Items, View Items) help move between pages and for logout click “Logout”.

7.Profile Page

This page shows user account details such as username, name, and contact number.And items posted by the logged-in user. Users can manage their posts.
The blue text “Delete post” is a link. Click it to delete the item post. Users can delete their account using “Delete Account” button.
